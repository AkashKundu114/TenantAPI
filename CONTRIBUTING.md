# Contributing to TenantAPI

Thank you for your interest in contributing to TenantAPI!

## Development Setup

1. Prerequisites:
   - [.NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
   - Git

2. Clone and Build:
   ```bash
   git clone https://github.com/AkashKundu114/TenantAPI.git
   cd TenantAPI
   dotnet restore
   dotnet build
   dotnet test
   ```

## Pull Request Guidelines

- Branch names should follow conventional prefixes: `feat/`, `fix/`, `docs/`, `chore/`.
- Ensure all tests pass prior to submitting a pull request.
- Keep commits atomic and descriptive.
